# Phase 2 Configs — Regime Mapping

Each config in this directory corresponds to a single point in parameter space.

Only Phase-2–relevant parameters may vary:
- seasonality amplitude / bias
- violence (exit friction)
- information (memory / lock-in)
- charisma (festival strength)

All other parameters must remain fixed.

Each config must state:
- which axis is being varied
- expected qualitative regime (hypothesis)
- unique random seed

Results are invalid without a logged config_resolved.yaml.
