# Phase 4 Design Draft — Hierarchy Geometry

Key question:
Do hierarchical phases exhibit tree-like or hyperbolic interaction structure?

Planned additions:
- interaction graph extraction
- structural metrics (tree-likeness, curvature proxies)
- association tests with hierarchy intensity

Acceptance tests (pre-implementation):
- graph extraction is deterministic and reproducible
- metrics are stable on controlled synthetic graphs
- hierarchical windows differ structurally from egalitarian windows on held configs

Output schema target:
- graph metric table by window
- alignment of structural metrics with `frac_hier` summaries
