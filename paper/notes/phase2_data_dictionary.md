# Phase 2 Data Dictionary

## 1) Run Artifact Columns

Source: `experiments/runs/phase2/run_index.csv`

- `run_id`: unique run directory identifier.
- `config_path`: config file path used for run.
- `seed`: random seed used by simulation.
- `status`: `SUCCESS` or `FAILED`.
- `retry_count`: number of retries used after initial attempt.
- `start_time`: run start timestamp (UTC).
- `end_time`: run end timestamp (UTC).
- `git_commit`: commit hash captured at run time.
- `schema_version`: resolved config schema version.
- `run_dir`: output directory for this run.
- `metrics_path`: canonical path to `metrics.csv`.
- `config_resolved_path`: canonical path to `config_resolved.yaml`.
- `seed_path`: canonical path to `seed.txt`.
- `git_commit_path`: canonical path to `git_commit.txt`.
- `failed_marker_path`: canonical path to `FAILED.txt` when `status=FAILED`,
  otherwise empty.
- `artifact_paths`: compact artifact-path summary for contract checks.
- `error`: flattened traceback when status is `FAILED`.

## 2) Metrics Columns

Source: `metrics.csv` per run

- `t`: simulation time step after burn-in filtering.
- `frac_hier`: fraction of agents in `authority_on` groups.
- `num_groups`: number of extant groups.
- `mean_group_size`: mean size across groups.
- `max_group_size`: largest observed group size at step `t`.
- `gini_prestige`: inequality of prestige distribution.
- `festival`: seasonal festival driver value (if logged).
- `crisis`: seasonal crisis driver value (if logged).

## 3) Regime Classifier Inputs

- primary signal: `frac_hier(t)`
- binary projection: `h(t) = 1[frac_hier(t) > tau]`
- optional seasonal driver for coherence: `crisis(t)` preferred, `festival(t)` fallback
- seasonal period: `seasonality.seasonal_period` from resolved config

## 4) Regime Classifier Outputs

Source: `experiments/runs/phase2/regime_labels.csv`

- `label`: one of `egalitarian`, `hierarchical`, `reversal`, `uncertain`.
- `confidence`: heuristic confidence in `[0, 1]`.
- `duty`: mean occupancy of `h(t)=1`.
- `switch_count`: number of state transitions in `h(t)`.
- `switch_rate`: `switch_count / (|T|-1)`.
- `max_dwell_hier`: max contiguous run where `h(t)=1`.
- `max_dwell_egal`: max contiguous run where `h(t)=0`.
- `seasonal_coherence`: max absolute lagged correlation vs seasonal driver.
- `seasonal_lag`: lag at which max coherence occurs.
- `thresholds_path`: threshold file used for labeling.
- `labeled_at`: labeling timestamp (UTC).

## 5) Interpretation Notes

- `uncertain` is an explicit outcome for borderline/contradictory runs.
- Stage 1 conclusions should use appearance language, not robustness language.
- Robustness claims require Stage 2 replicated cells and explicit criteria.

## 6) Robustness Verdict Outputs

Generated by:
- `scripts/phase2_robustness_verdict.py`

Primary outputs:
- `robustness_cells*.csv`: per-cell replicate counts, probabilities, and pass/fail verdict.
- `robustness_boundaries*.csv`: boundary-level aggregation of cell verdicts.

Key fields:
- `target_label`: label under test for robustness claims.
- `min_successes`, `min_replicates`: gating thresholds.
- `pass_target`: `1` if cell satisfies robustness criterion, else `0`.
- `boundary_pass`: `1` if boundary meets configured minimum passing-cell rule.

## 7) Stage 2 Figure Inputs

Generated by:
- `scripts/phase2_stage2_figure_inputs.py`

Primary outputs:
- `stage2_probability_map*.csv`: per-cell class probabilities for phase-diagram coloring.
- `stage2_uncertainty_overlay*.csv`: per-cell uncertainty metrics for overlays.

Key fields:
- `p_egalitarian`, `p_hierarchical`, `p_reversal`, `p_uncertain`: replicate-based probabilities.
- `entropy_bits`: Shannon entropy over the 4-label distribution.
- `entropy_normalized`: entropy normalized to `[0,1]` by dividing by `log2(4)`.
- `discord`: `1 - max(p_label)`, a simple disagreement indicator.

## 8) Strict Sanity-Pass Outputs

Generated by:
- `scripts/phase2_sanity_pass.py`

Primary outputs:
- `sanity_threshold_ensemble_runs.csv`: run-level relabeling across tau/settings.
- `sanity_threshold_ensemble_cells.csv`: cell-level probabilities and pass flags per setting.
- `sanity_threshold_stability_cells.csv`: per-cell stability across settings.
- `sanity_threshold_boundary_settings.csv`: strict boundary verdict per setting.
- `sanity_threshold_boundary_stability.csv`: boundary stability across settings.

Key fields:
- `variant`: `single_threshold` or `hysteresis`.
- `tau_center`, `tau_low`, `tau_high`: labeling setting coordinates.
- `mean_frac_hier` and `span_p95_p05_frac_hier`: direct checks for high-mean
  threshold-crossing behavior.
- `p_target_span`: sensitivity of target-label probability across settings.
- `pass_all` (cell) and `boundary_pass_all` (boundary): strongest invariance gates.
