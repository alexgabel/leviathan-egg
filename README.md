# Leviathan Egg

**Minimal agent-based models of reversible domination under seasonal forcing.**

This repository contains a reproducible research codebase exploring how
fission–fusion societies can exhibit:
- stable egalitarian organization,
- stable hierarchy,
- and seasonal reversals of political form,
including desynchronized political calendars across coexisting societies.

👉 **Project goals, scope, phases, and non-goals are defined in**
[`PROJECT_SUMMARY.md`](PROJECT_SUMMARY.md).  
That document is the authoritative alignment contract for this project.

## Status
Early-stage research codebase.  
Phase 0 complete (project alignment and scaffolding).  
Phase 1 (core engine) in progress.

## Reproducibility
All experiments are config-driven and seed-controlled.
Results without full configuration and metadata are considered invalid.
